# AI Visual Asset Intelligence

Crawl, enrich, and search visual assets with multimodal AI: end-to-end pipeline from web ingestion to a queryable image library.

## Architecture

Ingestion (Playwright crawl) -> multimodal captioning/enrichment -> indexed search API -> React exploration UI.

## Stack

TypeScript, Fastify, Prisma, Playwright, OpenAI APIs, React, Vite, npm workspaces

## Why this matters

Built as an Applied AI Architecture showcase: clear system boundaries, agent/tooling seams, and a path from prototype to operable demo.

## Safety
